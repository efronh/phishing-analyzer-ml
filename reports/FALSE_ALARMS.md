# Reducing false alarms

Generated by `experiments_false_alarms.py`. All thresholds are chosen on validation data. Neither hold-out set is used for training or tuning.

| version | rule features | training data | threshold picked on |
|---|---|---|---|
| v1 | raw counts (link count, summed URL score…) | Kaggle + Nazario/SA | Kaggle + Nazario/SA val |
| v2 | bounded (ratios, max, log, clipped) | Kaggle + Nazario/SA | Kaggle + Nazario/SA val |
| v2+val | bounded | Kaggle + Nazario/SA | + modern legit val |
| v3 | bounded | + 1547 modern legit (Python/Fedora/GNU 2024) | + modern legit val |

Operating points: **max_f1** maximizes F1 on validation. **fpr<=1%** is the lowest threshold whose validation false-alarm rate is at most 1%.
