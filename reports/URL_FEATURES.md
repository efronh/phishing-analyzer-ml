# URL features

Generated by `experiments_url.py`. Protocol, written before the first run: [`URL_FEATURES_PROTOCOL.md`](URL_FEATURES_PROTOCOL.md). The production model is compared with the same model plus 8 bounded URL features. Both use the production procedure (grouped 5-fold CV on 21506 training emails, Platt calibration, plateau threshold, refit on all data).

Naming: `v3`/`v4` in the JSON are **feature-set** numbers (`feature_version` 3 and 4), not the model versions of the README. Feature set 3 is the production model (README: v4+lure); feature set 4 adds the URL features.

## Decision

**The production model stays as it is.**

1. Primary, mean paired fold-F1 difference (+ URL − production): **-0.00019**, standard error 0.00044 → not passed.
2. Guard, no significant rise in false alarms on A, B or C → passed.

| set | false alarms only + URL makes | only production makes | McNemar p | + URL significantly worse |
|---|---:|---:|---:|---|
| A | 3 | 4 | 1 | no |
| B | 2 | 2 | 1 | no |
| C | 0 | 1 | 1 | no |
